## 4. Google Analytics 4 (GA4) Aanpassingen

### A. Custom Dimensions instellen

1. Ga naar https://analytics.google.com
2. Selecteer je property
3. Ga naar "Admin" (tandwiel linksonder)
4. Klik "Custom definitions" → "Custom dimensions"

**Maak deze custom dimensions aan:**

| Dimension naam | Scope | Parameter naam |
|----------------|-------|----------------|
| Service_Regio | Event | service_regio |
| Lead_Bron | User | lead_source |
| Project_Type | Event | project_type |

### B. Events configureren

**Check of deze events correct tracken:**
- [ ] `form_submit` (contactformulier)
- [ ] `phone_click` (telefoonnummer klikken)
- [ ] `whatsapp_click` (WhatsApp button)
- [ ] `offerte_aanvraag` (offerte button)

**Test door:**
1. Ga naar "Rapporten" → "Realtime"
2. Open je website in een nieuw tabblad
3. Klik op een telefoonbutton of formulier
4. Controleer of event verschijnt in realtime

### C. Conversies instellen

**Markeer deze events als conversies:**
1. Ga naar "Admin" → "Events"
2. Vink aan bij deze events:
   - [ ] `form_submit`
   - [ ] `phone_click`
   - [ ] `offerte_aanvraag`
