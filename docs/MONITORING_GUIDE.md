## 📊 What to Monitor Weekly

### Every Monday Morning (10 min check)

1. **Google Search Console - Performance**
   - Go to: https://search.google.com/search-console
   - Select: yannova.be property
   - Check "Performance" tab
   - Note down:
     - Total clicks this week
     - Total impressions
     - Average position (should gradually improve)
     - Click-through rate %

2. **Top Keywords Check**
   - In GSC, click "Queries" (Performance tab)
   - Look at top 20 queries
   - Are new keywords appearing? ✓
   - Are rankings improving? ✓
   - Example to track:
     - "wat kosten nieuwe ramen"
     - "renovatie premies 2026"
     - "crepi prijs"
     - "ramen antwerpen"

3. **Blog Traffic Check**
   - Go to: https://analytics.google.com
   - Select: GA4 property
   - Filter: Last 7 days
   - Check:
     - New blog article clicks
     - Blog traffic trend
     - Popular blog posts

## 🚨 Red Flags to Watch

### If you see this → Action

| Signal | Action | Priority |
|--------|--------|----------|
| Traffic drops 50% | Check GSC for errors, check robots.txt, check if pages indexed | 🔴 URGENT |
| Crawl errors spike | Fix errors in GSC, resubmit sitemap | 🔴 URGENT |
| Mobile score drops | Test Lighthouse, fix CSS, check viewport meta | 🟠 HIGH |
| Keyword drops 10+ spots | Analyze competitor, improve content, add links | 🟠 HIGH |
| 0 blog traffic after 2 weeks | Share on social, check search console | 🟡 MEDIUM |

## 🎲 What to Do If Traffic Isn't Growing

### Week 2-4 (No growth yet - normal)
- ✓ Sitemap submitted? Check GSC
- ✓ Pages indexed? Check "Coverage" in GSC
- ✓ Schema valid? Test with Rich Results Test
- → Wait another 2 weeks

### Week 4-8 (Still no growth - investigate)
1. **Check GSC for problems:**
   - Any crawl errors?
   - Any mobile issues?
   - Any security issues?
   → Fix immediately

2. **Check if pages are indexed:**
   - URL Inspection Tool for 5 pages
   - Are they "Indexed"? 
   - If not: Request indexing

3. **Check competition:**
   - Google "ramen antwerpen" 
   - Do competitors have more content?
   - Can we improve ours?

### Month 3+ (Still no growth - strategic review)
- Consider: Content update needed?
- Consider: Need backlinks?
- Consider: Need social promotion?
- Consider: Technical issue?
- → Get expert help
